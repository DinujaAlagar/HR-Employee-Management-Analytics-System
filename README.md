# HR Employee Management & Analytics System

> A web-based Human Resource Management System designed to centralize employee information and streamline attendance, leave, performance, and HR analytics processes.

---

## 📌 Project Overview

The **HR Employee Management & Analytics System** is a web-based Human Resource Management (HRM) application developed as an academic project.

The system is designed to support essential HR activities through a centralized digital platform. It allows HR personnel to manage employee information, monitor attendance, manage leave records, evaluate employee performance, and view HR-related analytics.

The project demonstrates how **Human Resource Management concepts can be integrated with information technology, database management, and web application development** to improve HR processes and support data-driven decision-making.

## 🚀 Key Features

### 👥 Employee Management

- View employee records.
- Manage employee information.
- Store contact details.
- Manage departments and positions.
- Track employment status.
- Organize employee information in a centralized system.

### 🕒 Attendance Management

- Record daily attendance.
- Track check-in and check-out times.
- Monitor present and late employees.
- Maintain attendance records.
- Support attendance analysis.

### 🏖️ Leave Management

- Record employee leave requests.
- Track leave types.
- Track leave start and end dates.
- Monitor leave status.
- Manage approved and pending leave information.

### 📊 Performance Management

The performance module supports employee evaluation based on:

- Productivity

- Overall performance
- Performance comments

### 📈 HR Analytics

The analytics dashboard provides:

- Department-wise employee analysis.
- Attendance analysis.
- Performance analysis.
- HR statistics.
- Visual data representation.
- Support for data-driven HR decisions.

⚙️ Installation & Setup

Follow the steps below to run the project locally.

1. Clone the repository
git clone https://github.com/DinujaAlagar/HR-Employee-Management-Analytics-System.git
2. Navigate to the project folder
cd HR-Employee-Management-Analytics-System
3. Create a virtual environment
python -m venv venv
4. Activate the virtual environment
Windows PowerShell
venv\Scripts\activate
Windows Command Prompt
venv\Scripts\activate
5. Install dependencies
pip install -r requirements.txt
6. Run the application
python app.py
7. Open the application

Open your web browser and visit:

http://127.0.0.1:5000
